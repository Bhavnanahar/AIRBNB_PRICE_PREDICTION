# 🏡 **Airbnb Price Prediction** 🤖

Welcome to the **Airbnb Price Prediction** project! This is an interactive web app built using **Streamlit** to predict the price of Airbnb listings based on various features like location, room type, and reviews. The model is trained using machine learning techniques to predict the nightly price of a listing.

## 🚀 **Features**
- **Interactive Web Interface** built with **Streamlit**
- **Model Prediction** for estimating Airbnb listing prices
- **Input Fields**:
  - Latitude and Longitude
  - Minimum Nights
  - Number of Reviews
  - Reviews per Month
  - Room Type (Private/Entire/Shared)

## 📈 **Tech Stack**
- **Machine Learning**: 🧠 `Scikit-Learn`, `Joblib`
- **Web Framework**: 🌐 `Streamlit`
- **Data Manipulation**: 🧳 `Pandas`, `NumPy`
- **Deployment**: 🌍 `Streamlit Cloud`, `GitHub`

## 📝 **How to Use**
1. **Launch the app** using the following link:  
   👉 [Airbnb Price Prediction App](https://airbnbpriceprediction-gfhmsaelpjygjtjncqjzjs.streamlit.app/)

2. **Enter the listing details**:
   - Input the **latitude**, **longitude**, **number of reviews**, **reviews per month**, **minimum nights**, and **room type**.
